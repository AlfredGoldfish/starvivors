# Simplified Asteroids-Style Reference Examples

Purpose: reference-only examples for moving Starvivors core ships, enemies, icons, and asteroids toward a simpler arcade-vector style.

These files are not promoted production assets. Use them to guide original Starvivors shapes, proportions, and readability rules.

## Direction

- Prefer clean geometric silhouettes over painterly sprites.
- Treat the classic Asteroids lesson as: black space, high-contrast outlines, very low detail, instant object recognition.
- Use simple primitives with small identity marks: triangle, wedge, hexagon, ring, bracket, starburst, notch, antenna, bay cutout.
- Keep fills minimal. Outlines, glow, and short inner fracture lines should carry most of the style.
- Reserve color for gameplay meaning, not decoration.

## Starvivors Translation

- Interceptor: narrow triangular dart, one forward nose line, cyan/white outline.
- Bulwark: broad blunt wedge or trapezoid, heavy shield arc, thicker stroke than Interceptor.
- Engineer: compact utility hull with small side pods or antenna marks, not a busier sprite.
- Basic chaser: diamond/arrowhead.
- Shooter: small saucer or chevron with a visible barrel notch.
- Tank: slow hexagon or blocky outline, thicker stroke.
- Charger: aggressive wedge with forward speed streaks.
- Sniper: long needle triangle, clear line-of-fire telegraph.
- Exploder: unstable starburst outline.
- Support/shield enemy: core shape plus bracket/halo.
- Carrier: large simple frame with bay notches, not a detailed ship illustration.
- Asteroids: rough 8-12 point polygons, tiered by size, stroke weight, and 1-3 internal crack lines.
- Icons: monoline symbols using the same stroke rules as ships and enemies.

## What To Avoid

- Photo-real asteroid texture.
- Small decorative panels that disappear at combat scale.
- Full-color shaded sprites that fight the HUD and projectile language.
- One-off icon styles per system.
- Using the downloaded Asteroids logo or classic-game marks as Starvivors branding.
