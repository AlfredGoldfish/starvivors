## Research Notes

- The original Asteroids arcade game used a vector monitor, which is the key visual lesson: lines, sharp geometry, and high readability.
  - Reference: https://en.wikipedia.org/wiki/Asteroids_(video_game)
- PixelatedArcade summarizes the visual consequence well: the arcade version used a black-and-white vector monitor with sharp geometric outlines.
  - Reference: https://www.pixelatedarcade.com/games/asteroids
