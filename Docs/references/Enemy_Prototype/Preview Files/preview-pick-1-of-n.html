Pick 1 of N Upgrades

Pattern
Live Preview
When triggered (level up, wave end, kill threshold), the game pauses and shows an overlay with N random upgrade cards. The player picks one. The chosen upgrade applies immediately and the game resumes. The defining mechanic of the modern survivor genre.
Trigger
Level up, wave clear, kill count, or timer
Choices
Usually 3, can be 2-5
Best for
Arena survivors, roguelites, any game with power scaling
Feel
Exciting decision moment — every pick changes your build
ArenaRPGRoguelite e.g. Vampire Survivors, Brotato, Halls of Torment
