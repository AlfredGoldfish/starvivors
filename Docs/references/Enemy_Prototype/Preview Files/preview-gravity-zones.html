Gravity

Different areas of the map have different gravity rules. Normal pulls down. Reverse pulls up — the ceiling becomes the floor. Sideways pushes horizontally. Zero-G lets you float freely. Each zone changes how the player moves, creating spatial puzzles and variety within a single level.

Reverse ↑

Sideways →
Horizontal pull — walls become floors
