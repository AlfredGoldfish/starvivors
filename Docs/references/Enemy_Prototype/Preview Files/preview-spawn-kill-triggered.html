The next batch only spawns after the current batch is completely eliminated. The player controls the pacing - fight fast and the next batch comes fast. Fight slow and you get more breathing room. Creates a player-driven rhythm where speed is rewarded but rushing is risky. Clear counter shows progress toward the next trigger.
