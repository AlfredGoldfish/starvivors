Three enemy roles that protect each other. The tank soaks damage with massive HP. The healer stands behind it, restoring the tank's health. The shield bearer blocks the path to the healer. The player must learn target priority: break the shield → kill the healer → finish the tank. Attacking the tank first is a trap.
Tank
Huge HP, no shield, just raw durability
Healer
Restores nearby ally HP, squishy, high priority target
Shield
Blocks shots to healer, shield breaks after enough hits
Lesson
Target priority: shield → healer → tank
