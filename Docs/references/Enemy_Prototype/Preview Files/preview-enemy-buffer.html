A support enemy that projects a visible aura making all nearby allies faster and stronger. Some enemies camp inside the zone, others chase but lose the buff when they leave. Kill the buffer and every buffed enemy immediately weakens — slower, smaller, easier to clean up. The buffer is always the priority target.
