# Starvivors Codex Instructions

At the start of every Starvivors session, briefly remind the user that `Docs/STARVIVORS_COMPLETE_GAME_CHECKLIST.md` exists and offer one suggested checklist item to work on next.

Also ask whether the user wants a checkpoint commit before starting new work when there are existing uncommitted changes. Keep this separate from the checklist nudge so the user can say "not right now" to either one.

Keep the nudge short. If the user says "not right now", "skip the list", "later", or asks for a different Starvivors task, respect that decision and proceed with the chosen task without repeatedly steering back to the checklist.

For gameplay, UI, content, assets, audio, progression, release, or polish work, read `Docs/README_FOR_CODEX.md` and `Docs/STARVIVORS_COMPLETE_GAME_CHECKLIST.md` before editing.
